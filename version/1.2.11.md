## 关键改动说明

### 1) 登录与昵称访客模式
- `src/components/Login.tsx`
  - 新增访客昵称输入框。
  - 访客进入改为调用 `POST /api/guest-login`。
  - 昵称为空时前端阻止提交并给出提示。

- `server.ts`
  - 新增 `POST /api/guest-login`。
  - 服务端昵称校验（长度、字符集、保留昵称限制）。
  - 昵称写入 Redis：
    - `kuromi:guests:nicknames`（集合）
    - `kuromi:guests:recent`（有序集合）

### 2) Post 页面迁移
- `src/components/PostPage.tsx` (new)
  - 承接原 Home 的帖子列表时间轴展示与右侧滚动轴交互。
  - 保持 Kuromi 站点配色与背景氛围。

- `src/components/TopNav.tsx`
  - 新增导航项 `post`，路径 `/post`。
  - `post` 导航激活态覆盖 `/post` 与 `/posts/:id`。

- `src/App.tsx`
  - 新增路由类型 `posts`，解析 `/post`（兼容 `/posts`）。
  - 路由渲染中接入 `PostPage`。
  - 帖子详情返回按钮改回 `/post`。

### 3) Home 留言板
- `src/components/Home.tsx`
  - 移除帖子时间轴，改为 Home 公告 + 留言入口布局。
  - 左侧嵌入留言板组件。

- `src/components/GuestMessageBoard.tsx` (new)
  - 获取留言：`GET /api/messages`。
  - 发布留言：`POST /api/messages`。
  - 留言使用当前登录昵称，空昵称禁止提交。

- `server.ts`
  - 新增 `GET /api/messages` 与 `POST /api/messages`。
  - Redis 存储：
    - `kuromi:messages`
    - `kuromi:messages:id`

### 4) 帖子详情评论与阅读数
- `src/components/PostDetail.tsx`
  - 删除顶部下方双图横条区块。
  - 新增阅读次数展示（badge + meta）。
  - 新增评论输入、发布、反馈、评论列表。
  - 评论提交调用 `POST /api/posts/:id/comments`，昵称为空时阻止。

- `server.ts`
  - `GET /api/posts/:id` 增加阅读计数自增并返回。
  - `GET /api/posts` 增加返回 `viewCount`。
  - `POST /api/posts` 初始化阅读计数。
  - `DELETE /api/posts/:id` 清理阅读计数 key。
  - `POST /api/posts/:id/comments` 强化昵称/内容校验。

### 5) 编辑页权限校正
- `src/components/PostEditorPage.tsx`
  - 编辑页权限判断改为基于 `currentUser.role === "admin"`，避免昵称校验策略调整后管理员被误判。

## 新增字段（接口/类型）

### TypeScript 类型新增
- `src/types.ts`
  - `Post.viewCount?: number`
  - `MessageItem` 类型：
    - `id: number`
    - `author: string`
    - `content: string`
    - `createdAt: string`

### 接口新增/扩展
- `POST /api/guest-login`
  - Request: `{ nickname: string }`
  - Response: `{ success: boolean, user?: string, role?: "guest", message?: string }`

- `GET /api/messages`
  - Response: `MessageItem[]`

- `POST /api/messages`
  - Request: `{ author: string, content: string }`
  - Response: `{ success: boolean, message: MessageItem }`

- `GET /api/posts`
  - 每个帖子新增 `viewCount`

- `GET /api/posts/:id`
  - 帖子详情新增 `viewCount`
