# 1.2.18

## 本次目标
- 仅改造 Home 页组件的“滚动后出现”入场效果：下滑进入视口时再展示，每个区块使用不同动效。

## 修改文件
- `src/components/Home.tsx`
- `version/1.2.18.md` (new)

## 关键改动说明
- 为 Home 各主区块接入 `framer-motion` 的 `whileInView` 触发机制，改为滚动进入后再显示。
- 各分区采用差异化入场动画（上浮、侧滑、轻旋、裁剪展开、弹性进入、淡入上移），避免统一模板化动画。
- “联动流程”卡片新增错峰入场（stagger）效果，同时保留原有流程高亮轮播逻辑。
- 增加 `prefers-reduced-motion` 兜底：系统偏好减少动画时关闭滚动入场，保证可访问性。
- 继续保留原业务逻辑与交互：访客昵称模式、留言板、管理员入口、帖子跳转、壁纸切换、运行时长计算等未删除。
- 页脚版本标识更新为 `Home v1.2.18`。

## 审美与素材对齐
- 参考 `src/public/kuromi` 素材主视觉（霓虹黑粉、贴纸感、糖果质感）校准动画节奏与出现方式。
- 组件仍使用当前 Shadcn 风格 UI 组件体系（`Card`/`Badge`/`Button`）并结合 `Animate.css` 与 `Framer Motion`。
