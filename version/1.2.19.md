# 1.2.19

## 本次目标
- 登录页左侧移除底部三张装饰图。
- 右侧改为“管理员登入 / 访客登入”可切换模式，并保持现有业务逻辑可用。

## 修改文件
- `src/components/Login.tsx`
- `version/1.2.19.md` (new)

## 关键改动说明
- 使用现有 Shadcn 无头组件封装 `Tabs`（`src/components/ui/tabs.tsx`）实现双模式切换，避免手搓 tab 逻辑。
- 保留原有管理员登录请求 `/api/login` 与访客登录请求 `/api/guest-login`，接口、入参、成功回调逻辑未改变。
- 左侧展示区删除三张图片资源块（`bg_about/bg_music/bg_movies`），改为单一“ENTRANCE NOTICE”信息卡，减轻视觉噪声。
- 右侧登录区拆分为两个独立表单：
  - 管理员模式：账号 + 密码 + 管理员登录按钮
  - 访客模式：昵称输入 + 访客进入按钮
- 在模式切换时清空错误提示，避免跨模式错误文案污染。
- 增加 `handleGuestSubmit`，确保访客模式支持键盘 Enter 提交。
- 继续使用 `Framer Motion` 和 `Animate.css` 做入场与过渡动画，维持 Kuromi 氛围下的动感表现。

## 审美审查（Kuromi 风格）
- 主色仍保持黑夜底 + 玫粉/青蓝霓虹点缀，符合现有站点视觉语义。
- 保留贴纸漂浮动效与玻璃质感边框，不破坏原页面“秘密基地”氛围。
- 右侧操作区由混合表单改为分模式入口，信息层级更清晰，移动端也更易点击。

## 业务与安全审阅
- 未删除有效业务逻辑：管理员与访客登录流程完整保留。
- 输入处理延续既有行为：管理员账号 `trim`、访客昵称 `trim`、访客昵称长度上限 `24`。
- 错误处理保持原策略：网络异常与服务端返回错误均有提示。
- 组件改造仅发生在登录页展示层，不影响帖子、评论、留言等后续业务。

## 响应式检查
- 根布局仍为 `lg` 双栏、小屏单栏。
- 登录区 tab 与按钮为整行触达，移动端输入和点击更稳定。
