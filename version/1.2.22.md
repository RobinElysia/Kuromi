# 1.2.22

## 本次目标
- 适配导航栏手机端布局与交互。
- 在 `post` 页与 `trails` 页（`/tags`）手机端隐藏滚动条显示。

## 修改文件
- `src/components/TopNav.tsx`
- `src/components/PostPage.tsx`
- `src/components/TagsPage.tsx`
- `version/1.2.22.md` (new)

## 关键改动说明
- `TopNav.tsx`
  - 新增移动端折叠菜单（`md` 以下）：Logo 行 + 菜单按钮 + 折叠内容面板。
  - 折叠菜单内保留站内搜索、导航入口和 Visitor Mode 标识。
  - 桌面端结构与原有逻辑保持一致（导航高亮、`onNavigate`、搜索输入行为不变）。
  - 使用 `Framer Motion` 实现移动端菜单展开/收起过渡动画，继续遵循当前 Kuromi 视觉风格。

- `PostPage.tsx`
  - 新增移动端滚动条隐藏样式注入函数（按需注入到 `<head>`，避免重复注入）。
  - 页面挂载时根据媒体查询切换 `body.kuromi-mobile-hide-scrollbar`，卸载时清理。
  - 页面根容器增加 `overflow-x-clip`，避免手机端横向溢出导致滚动条出现。

- `TagsPage.tsx`
  - 同步 `PostPage` 的移动端滚动条隐藏策略（样式注入 + `body` class 切换 + 卸载清理）。
  - 页面根容器增加 `overflow-x-clip`，降低复杂动画层在小屏上的横向溢出风险。

## 业务与安全审阅
- 未删除现有业务逻辑：帖子拉取、trails 联动、导航跳转、访客模式行为均保持。
- 未新增后端接口、权限边界或敏感信息处理逻辑。
- 滚动条隐藏仅在手机端和目标页面生效，不影响桌面端可见性。

## 编码与可运行性检查
- 编码：新增内容使用 UTF-8。
- 代码检查：`npm.cmd run lint` 通过（`tsc --noEmit`）。
