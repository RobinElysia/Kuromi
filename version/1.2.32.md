# 1.2.32

## Goal
- Add card switching by drag and horizontal swipe.
- Keep card click flip + jump behavior unchanged.

## Modified Files
- `src/components/TagsPage.tsx`
- `version/1.2.32.md` (new)

## Changes
- Expanded drag trigger conditions:
  - Previously: only primary mouse left button could trigger drag switch.
  - Now: mouse left button or touch/pen pointer can trigger drag/swap.
- Added safer pointer lifecycle handling:
  - New `handleCardPointerCancel` resets drag flags to avoid stale drag state.
- Kept switch behavior on horizontal drag end:
  - Existing threshold + velocity logic in `handleCardDragEnd` remains.
- Updated interaction copy to match behavior:
  - Tab caption: `拖拽/左右滑动切换 · Click 翻转`
  - Card hint: `拖拽/左右滑动切换当前卡片 / Click 翻转`
- Added touch gesture friendliness:
  - `touch-pan-y` class on draggable focused card to improve mobile swipe coexistence with page scroll.

## Preserved Behavior
- Only focused current card can trigger drag-based switching.
- Click still flips and jumps to corresponding dispatch/tag.
- Kuromi visual style and responsive layout remain unchanged.

## Security / Maintainability
- No new API/network surface introduced.
- Logic stays local to `TagsPage.tsx`; code path is explicit and readable.

## Validation
- Passed: `npm.cmd run lint` (`tsc --noEmit`).
