# 1.2.33

## Goal
- Set the global Chinese font to the dedicated font file under `src/public/front/`.

## Modified Files
- `src/index.css`
- `version/1.2.33.md` (new)

## Changes
- Added a new global font-face:
  - `KuromiChinese` -> `./public/front/chinese_front.ttf`
- Updated the global body font stack:
  - `--font-body` now prefers `KuromiChinese`, then falls back to the existing `KuromiSans` and system Chinese fonts.
- Expanded global font inheritance:
  - `button`, `input`, `textarea`, and `select` now explicitly inherit the same body font stack for more consistent Chinese rendering across the site.
- Added `font-synthesis: none` on `body`:
  - Reduces synthetic bold/italic rendering artifacts and keeps the selected Chinese font more predictable.

## Preserved Behavior
- Existing Kuromi display font for headings remains unchanged.
- Existing cursive/script font remains unchanged.
- No page logic, API behavior, or component business flow was modified.

## Security / Maintainability
- No new runtime dependency or network request introduced.
- Font loading stays local to the bundled project assets.
- Fallback font chain remains intact to avoid broken rendering if the custom font fails to load.

## Validation
- Passed: `npm.cmd run lint` (`tsc --noEmit`).
