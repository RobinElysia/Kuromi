# 1.2.36

## Goal
- 按新的职责划分重构 Home 留言区：左侧 `Home` 卡片负责弹幕展示，右侧 `GuestMessageBoard` 只负责个人信息、输入与发送。
- 保持原有 Redis 留言接口与昵称访客模式不变，同时避免重复请求和状态分裂。

## Modified Files
- `src/components/Home.tsx`
- `src/components/GuestMessageBoard.tsx`
- `version/1.2.36.md` (new)

## Changes
- `src/components/Home.tsx`
  - 新增留言数据读取状态，统一在 Home 内拉取最近 24 条消息。
  - 在 `HOME BOARD` 左侧卡片中重写弹幕展示区，加入实时弹幕流、加载态、空状态和错误态。
  - 保留 `prefers-reduced-motion` 降级逻辑，用户偏好减少动态时自动切换为静态列表。
  - 新增留言创建回调，右侧发送成功后直接同步更新左侧弹幕展示。

- `src/components/GuestMessageBoard.tsx`
  - 移除弹幕渲染职责，改为纯右侧控制面板组件。
  - 保留昵称输入、留言输入、提交校验、错误反馈与发送按钮。
  - 新增 `latestMessage`、`messageCount`、`onMessageCreated` props，用于展示摘要和回传新留言。
  - 继续不显示“留言发布成功”提示，成功后只清空输入并回推消息。

## Preserved Behavior
- 访客模式仍然只依赖昵称，不新增注册流程。
- 留言仍然写入 Redis，接口路径与后端协议未变化。
- 最近消息条数上限仍为 24。
- 留言失败时仍然显示错误提示。

## Security / Maintainability
- 未新增第三方依赖，继续复用项目已有的 `framer-motion` 和现有 UI 组件。
- Home 持有单一消息源，避免左右区域各自请求造成不同步。
- 输入内容仍走后端既有校验链路，没有绕过长度和内容限制。
