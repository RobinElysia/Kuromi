## Static Deployment Notes
- 静态生产环境下，数据存储在浏览器本地，不再连接 Redis。
- 这意味着：
  - 同一浏览器内数据可持久化
  - 不同设备/浏览器之间不会自动共享内容
- 如果仍需要真正的多端共享数据，必须保留服务端 API。

## Admin Hash Setup
- 打包前请在生产环境变量中提供两位管理员密码的 SHA-256 十六进制摘要。
- 可参考本地生成方式：

```bash
node -e "const crypto=require('crypto');console.log(crypto.createHash('sha256').update('你的密码').digest('hex'))"
```
