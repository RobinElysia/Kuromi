# 2.0.0

## 本次目标
- 将 Home / 登录入口中关于 RobinElysia 与 Meow 的管理员账号逻辑升级为“仅双管理员可注册并登录”。
- 管理员凭证改为写入 Redis 持久化，替代原有明文硬编码登录。
- 保留访客昵称模式，不破坏帖子、评论、留言板、图片上传等既有业务。

- `src/components/PostDetail.tsx`
- `src/components/PostEditorPage.tsx`

- `version/2.0.0.md` (new)

## 关键改动说明
- 后端新增 `POST /api/admin/register`：
  - 仅允许 `RobinElysia` 与 `Meow` 两个账号名。
  - 注册时要求输入对应身份校验码。
  - 若账号已存在则拒绝重复注册。
- 后端 `POST /api/login` 改造：
  - 移除原先用户名 + 明文密码硬编码判断。
  - 改为从 Redis 读取管理员凭证进行校验。
- 管理员密码存储改造：
  - 使用 Node 内建 `crypto.scrypt` + 随机 salt 生成密码哈希。
  - 使用 `timingSafeEqual` 做恒定时长比较，避免直接字符串比较。
  - Redis 键为 `kuromi:admins:<username>`。
- 登录页改造：
  - 新增 `登录 / 注册 / 访客` 三态入口。
  - 注册页仅支持 `RobinElysia` 与 `Meow` 选择，不提供开放式注册。
  - 注册成功后自动登入。
- 运行模式修正：
  - `src/lib/runtimeConfig.ts` 默认回退到 `server` 模式，避免生产构建意外落回浏览器本地存储，确保本次管理员数据走 Redis。
- 文案同步：
  - Home、Post 详情、Post 编辑页同步改为“仅双管理员可注册登录，访客昵称模式保留”。

## Redis 数据设计
- 管理员凭证键：`kuromi:admins:RobinElysia`
- 管理员凭证键：`kuromi:admins:Meow`
- 值结构：
  - `username`
  - `passwordHash`
  - `passwordSalt`
  - `createdAt`
  - `updatedAt`

## 审美审查（Kuromi 风格）
- 登录页保留 shadcn 风格卡片结构，并延续现有 Kuromi 玻璃态、粉青渐变、贴纸漂浮动效。
- 交互使用 `Framer Motion` 做入场与悬浮动画，保持当前站点视觉语言一致。
- 布局对移动端和桌面端均可自适应，未引入固定宽高阻塞。

## 安全与业务审阅
- 未删除访客昵称模式，原有留言、评论、帖子浏览逻辑保持不变。
- 管理员注册严格限制账号名，不开放任意用户注册。
- 密码不再以明文形式参与持久化存储。
- 登录失败、未注册、重复注册、校验码错误等状态都有明确返回信息。
- 保留图片上传管理员校验逻辑，未放宽权限边界。
